# موقع أفنان الفائقة (الموقع الثاني)

- `content/`: كل المحتوى اللي بيتعدل من لوحة التحكم (الخدمات، المقالات، القصص، البرامج، الأرقام).
- `templates/`: قوالب الصفحات.
- `static/`: التصميم والسكربتات والصور.
- `admin/`: لوحة التحكم (افتحها على `/admin`).
- `build.py`: يبني الموقع في `dist/` (Cloudflare بيشغّله لوحده بعد كل حفظ).

إعدادات Cloudflare: أمر البناء `python3 build.py`، وأمر النشر `npx wrangler deploy`.
